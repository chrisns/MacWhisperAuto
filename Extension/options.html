Custom meeting sites

Recording starts while the page title contains the text you give, and stops when the title no longer contains it. These rules stay in this browser only.

No custom sites yet.

URL pattern examples: https://*.example.com (example.com and every subdomain), call.example.com, https://call.example.com/room/*. A pattern without a path gets /*.

Save asks the browser for access to each site. Reload any open tab for the site after you save.

MacWhisper source is the item that MacWhisperAuto picks under MacWhisper's "Record Meeting" menu. Auto uses the browser that this extension runs in. Pick Comet or Chrome only to override it.

Built-in sites (Google Meet, Teams, Zoom, Slack, Chime) use their own detection. A custom rule for those sites has no effect.
